Generated by `research/scripts/38_selective_prediction.py`. The base classifier is condition A of script 36 -- `hfl/chinese-roberta-wwm-ext-large` over the full paragraph, five folds, the same protocol as the rest of the project. Selective prediction leaves that classifier untouched and only chooses which of its predictions to keep.

## Reading

Abstention always raises accuracy on what is kept, so the comparison that means anything is between signals at the same coverage, and against the random column, which is what pure coverage reduction buys.

A criterion-mismatch account predicts that the guideline-independent features find errors the model's own confidence does not, because those errors are not failures of capability: the model is confident and consistent, it is applying a criterion the annotators did not use. A plain capability account predicts confidence should dominate.

One result here cuts the other way and has to be read alongside the rest. The criterion signal wins on accuracy at every coverage and loses on macro-F1 at every coverage. That is not a contradiction; it is the same effect this project measured when it forced the label hierarchy to be consistent. Declining a row removes it from its class, and the rows the criterion features decline are concentrated in `Not Clear`, the smaller and harder class. Macro-F1 weights that class equally with `Clear`, so shrinking it costs more than the accuracy it buys. Under accuracy -- what an auditor reading the kept rows actually experiences -- the ordering reverses.

Two independent findings in this project therefore have one cause: under an imbalanced macro-F1, an intervention that trades rare-class coverage for majority-class correctness is penalised even when it improves the decisions a user sees.
