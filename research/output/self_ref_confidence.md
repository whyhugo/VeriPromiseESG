# Does a learned confidence token see a criterion mismatch?

Generated by `research/scripts/44_self_ref_confidence.py` with `Qwen/Qwen3-8B`, 4-bit base and LoRA, following Self-REF (Chuang et al., ICML 2025). Trained on the 1345 train+val rows with `evidence_status=Yes`, evaluated once on the 1335 test rows.

| | base model | after Self-REF |
|---|---:|---:|
| test accuracy | 0.770 | 0.840 |

The accuracy gain is ordinary supervised fine-tuning on 1345 labelled rows and is not attributable to the confidence tokens; it is reported because it bears on what the rest of this project has found. The guideline's words did not convey the criterion to any model. Labelled examples conveyed a usable part of it to this one.

## Reading

**The prediction this script was written to test is wrong.** The expectation was that a confidence token, trained on whether the model's own answer had been right, would detect capability errors and miss a criterion mismatch, because on the disputed rows the model is confident and consistent rather than uncertain. It does not miss them: it reaches 0.7541 AUC on those rows and gives them a mean confidence of 0.5233 against 0.7666 elsewhere.

The reason it does not is visible in the accuracy row, and it is the more interesting half of this result. Fine-tuning on 1345 labelled rows moved the model from 0.770 to 0.840. The criterion that no wording of the guideline conveyed to any model -- not the published text, not a prompt containing it, not the four criteria asked one at a time -- was conveyed by examples. Once the model has absorbed part of that criterion, its uncertainty tracks it, and the disputed rows are exactly where the absorption is thinnest.

A second correction belongs here. Against a softmax baseline taken from the *same* fine-tuned model, the confidence token's advantage is small. The large gap is against the base model's softmax, which is not the comparison to make when the token is read off the tuned model. This does not contradict the original paper, whose datasets and baselines differ, but on this task most of what the token provides is available from the tuned model's own output distribution.

Read against the rest of the project, the finding is consistent and narrow: **words did not transmit this criterion and labelled examples did.** That is also why a fine-tuned 330M-parameter encoder outscores four zero-shot frontier models on the same rows.
