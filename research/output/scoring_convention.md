## What the convention is worth

`lenient` is the convention this project does **not** use: an empty response and an `N/A` both become `Clear`. `strict` is the one it does: failures excluded, `N/A` wrong. The gap is the size of the free marks.

## The unanimity split

A row is unanimous only if all four models actually answered it. The lenient column shows what a coerced failure would add: rows where three models answered and the fourth did not, which are not unanimous in any useful sense.

| | 寬鬆（失敗計為 Clear） | **本文（排除失敗）** |
|---|---:|---:|
| 四模型一致 | 770 | 742 |
| 一致且正確（對照組） | 621 | 595 |
| 一致但錯誤（爭議組） | 149 | 147 |

寬鬆慣例會多算 28 段——那些段落實際上只有三個模型作答（26 段會落入對照組、2 段落入爭議組）。**因此本文一律寫「四個模型都作答且答案相同」，而不是「四個模型答案相同」。**

## 錯誤相關係數

兩個系統各自的「這一列答錯了沒」向量之間的相關係數（Matthews / phi）。只在兩者都有作答的列上計算。

| 組合 | $\phi$ | 計算列數 |
|---|---:|---:|
| 四個前沿模型彼此（6 組配對平均） | **0.537** | --- |
| 本文微調編碼器 與 Qwen3-8B | **0.307** | 1335 |

在寬鬆慣例下前沿模型那一列會是 0.498，因為被當成 `Clear` 的失敗回應在四個模型之間製造了假的一致；上表為排除失敗後的值。

## 為什麼這件事值得單獨寫一節

失敗回應若被當成免費的 `Clear` 猜測，受益最大的正是失敗次數最多的那個模型——這個慣例會**獎勵不可靠**。它同時汙染分歧分析：一段只有三個模型作答的段落會被算成「四個模型一致」。本專案每一支程式都在來源處採用本節的嚴格慣例，分組定義只有一份，在 `research/scripts/probe_groups.py`。
