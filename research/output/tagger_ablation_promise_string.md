# What each design choice in the clause tagger is worth

Generated by `research/scripts/42_tagger_ablation.py` on `promise_string`. Every variant uses the same folds, epochs, batch size and learning rate as the published run; only the named choice changes. The decision threshold is refitted out-of-fold for each variant, so no variant is helped by a threshold tuned for another.

Any ablation below that moves char-F1 by less than about 0.0066 is inside seed noise and should not be read as an effect.
