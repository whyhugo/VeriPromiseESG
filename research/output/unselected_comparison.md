## Reading

**The first table reverses what script 43 appeared to show.** On rows nobody selected, the open model has the *weakest* discrimination of every system here -- +0.172 against +0.384 to +0.467 for the frontier models and +0.461 for the fine-tuned transformer -- and its macro-F1 is below all four. Its apparent advantage on the disputed rows was the selection, not the model. The corrected claim is narrow: the open model reproduces the *substitution* on a within-model comparison, which is what script 43 was built to test, and nothing about its relative accuracy survives.

**The second table is a genuine gain, and it is not on macro-F1.** Averaging the fine-tuned transformer with the zero-shot open model raises accuracy from 0.8052 to 0.8300 with a bootstrap interval that excludes zero, while macro-F1 moves +0.0087 with an interval that does not. The out-of-fold search put weight 0.45 on a model that is worse than the transformer on every column, which only pays if the two fail on different rows -- so the bias is present in both but not to the same degree, and the difference is worth something.

This is the third time in this project that an intervention improves the decisions a user would see while macro-F1 declines to record it. The first was forcing the label hierarchy to be consistent; the second was criterion-based abstention. A measure that gives a class with three test instances the same weight as one with 1,106 will keep producing this disagreement, and it is a property of the measure rather than of the interventions.
