Generated by `research/scripts/42_tagger_ablation.py` on `evidence_string`. Every variant uses the same folds, epochs, batch size and learning rate as the published run; only the named choice changes. The decision threshold is refitted out-of-fold for each variant, so no variant is helped by a threshold tuned for another.
