# LLM augmentation for the starved classes

Generated by `research/scripts/19_llm_augmentation.py`. Generator `Qwen/Qwen3-8B`, guided minimal-edit prompting from a real paragraph of the adjacent class. Classifier `hfl/chinese-roberta-wwm-ext-large`. All evaluation is on the real 2,000-row test set; synthetic data is only ever added to training.

| target class | synthetic paragraphs kept |
|---|---:|
| `eq_misleading` | 300 |
| `eq_notclear` | 300 |
| `es_no` | 300 |

## Reading

**Augmentation hurts in every condition.** `evidence_quality` drops from 0.4350
to 0.3994, 0.4039 and 0.3371; `evidence_status` from 0.6776 to 0.6188. Adding
both synthetic sets at once is worst, taking `Clear` from 0.7641 to 0.3946 -- 600
synthetic rows against 2,000 real ones is enough to corrupt the majority class.

**300 synthetic Misleading examples produce exactly zero recall on the real
three.** The class F1 is 0.0000 in every condition, unchanged. Together with
scripts 09 and 11 this closes the loop in both directions: `Misleading` cannot be
*recognised* from relatedness or from its definition, and it cannot be
*generated* from that definition either. Whatever the annotators were tracking
is not recoverable from the guideline text by this model, in either direction.

**Where the `evidence_status` numbers do move is the informative part.** Recall
on `No` rises, 0.6759 to 0.7621, while its F1 falls, 0.5498 to 0.4533. The
synthetic examples successfully teach the model to say `No` more often, and it
says it on the wrong rows. Precision collapses faster than recall improves.

That is the same shape as the threshold sweep in script 18, which raised recall
from 0.6414 to 0.8897 and lost macro-F1 monotonically the whole way. Two
unrelated interventions -- more data for the class, and a lower bar for
predicting it -- produce the same trade at the same place. Neither the size of
the training set nor the position of the decision boundary is what limits this
class; the model's ranking of the rows is.

**Why guided editing was not enough.** The prompt asked for the minimal edit that
flips the label, which should keep register and length while moving the example
across the boundary. That it degraded the majority class instead suggests the
edits moved further than intended -- producing text that is recognisably
generated rather than text that is genuinely borderline. A stricter filter, for
instance keeping only generations a held-out classifier finds hard, would be the
next thing to try, but the `Misleading` result would not change: there is nothing
to filter towards when zero of 300 attempts land.
